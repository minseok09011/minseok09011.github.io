# minseok09011.github.io

Personal academic homepage, based on [academic-homepage](https://github.com/luost26/academic-homepage) by luost26.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

## Structure

- `_data/profile.yml` — name, bio, links, education
- `_data/navigation.yml` — top navbar links
- `_data/display.yml` — homepage section toggles
- `_publications/` — publications (bibtex-free, one markdown file per paper)
- `index.html`, `publications.html` — pages
